# Fase 3.5 — Plan 2: Real PHP image + DB connectivity — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the PHP health-skeleton with the real combined image serving **Distribuidor** (raw PHP) + **SerfelWeb** (CodeIgniter) from one `php:5.6-apache` container, connected to the `serfel` RDS DB, verified in `dev`.

**Architecture:** Builds on the deployed Fase 3.5 foundation (branch `feat/phase3.5-rehost-foundation`). One Fargate service, one ALB behind the locked-down CloudFront front door. This plan swaps the image, wires the apps' DB config to the injected Secrets Manager env, relaxes RDS TLS enforcement (legacy `mysql_*` can't do TLS), and forwards the real Host so redirects/base_url point at CloudFront instead of the ALB DNS.

**Tech Stack:** Docker (`php:5.6-apache`, ARM64), ECS Fargate, ALB, CloudFront, RDS MariaDB, SST v3 (Pulumi), AWS CLI.

```dockerfile
# Real combined image: Distribuidor (raw PHP, mysql_*) + SerfelWeb (CodeIgniter,
# mysqli), one Apache doc root. PHP 5.6 is EOL. Built ARM64 to match the task def.
FROM php:5.6-apache

RUN echo "ServerName localhost" >> /etc/apache2/apache2.conf \
    && docker-php-ext-install mysql mysqli pdo pdo_mysql mbstring \
    && a2enmod rewrite

# SerfelWeb relies on .htaccess rewrites — enable AllowOverride for the doc root.
RUN printf '<Directory /var/www/html/>\n    AllowOverride All\n    Require all granted\n</Directory>\n' \
      > /etc/apache2/conf-available/allow-override.conf \
    && a2enconf allow-override

COPY Distribuidor/ /var/www/html/Distribuidor/
COPY SerfelWeb/   /var/www/html/SerfelWeb/
COPY health.php   /var/www/html/health.php

EXPOSE 80
HEALTHCHECK --interval=30s --timeout=3s CMD curl -f http://localhost/health.php || exit 1
```
*(If a later step shows a missing-extension error for a tested page, add it here — e.g. `gd`, `zip`.)*

## Notes / carry-forwards beyond Plan 2
- **Reverse-proxy scheme:** with AllViewer, Apache sees http (CloudFront→ALB is http-only) and may emit `http://` redirects that CloudFront upgrades to https (extra hop). If a redirect loop or mixed-content appears, forward `CloudFront-Forwarded-Proto` / set `HTTPS` env and adjust the app. Not expected for the tested pages.
- **Distribuidor report/PDF pages** hardcode `"localhost"` as the DB host in `Ventas/Reportes/*` (TCPDF/Jasper) — out of scope; env-repoint them when those flows are exercised.
- **Prod domain:** `base_url=''` auto-detects the CloudFront host now; set the real domain at go-live (Fase 6).
- **Basic Auth for node** and the real authorizer-against-DB-users change remain Plans 4/5.
