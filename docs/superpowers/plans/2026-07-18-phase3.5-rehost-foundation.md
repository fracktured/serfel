# Fase 3.5 — Rehost Foundation (skeleton end-to-end) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the complete rehost skeleton in `dev` — CloudFront → {S3 legacy-Angular slot, node HTTP API with Basic Auth, internal ALB → Fargate PHP} → RDS — with a minimal real PHP 5.6 health container and the real Basic Auth authorizer, so every route, authorizer, and network path is proven before the real legacy apps are dropped in (Plans 2–6).

**Architecture:** Additive to the existing SST v3 app. New infra lives under `serfel/infra/rehost/*` and is imported last in `sst.config.ts`, leaving the Phase 3 PoC (products Lambda, Cognito API, new frontend) completely untouched. PHP runs as a container on ECS Fargate behind an internal ALB; the two Express apps become Lambdas fronted by an HTTP API with a Basic Auth Lambda authorizer; a rehost-owned CloudFront distribution path-routes to all three plus the legacy Angular S3 site. This plan builds each slot with health-check-level content; Plans 2–6 replace that content with the real apps.

**Tech Stack:** SST v3 (Pulumi `aws.*` + `sst.aws.*`), TypeScript, Hono, mysql2, Vitest, Docker (`php:5.6-apache`), ECS Fargate, ALB, ECR, API Gateway HTTP API, CloudFront, S3.

## Global Constraints

- **Region:** `us-east-1` (matches `sst.config.ts`).
- **Additive only:** never modify `infra/api.ts`, `infra/auth.ts`, `infra/frontend.ts`, or `lambdas/products/*`. The products PoC and its Cognito API must keep working unchanged.
- **Separate HTTP API** for the rehost node Lambdas (independent lifecycle from the products API), per design §5.
- **Resource naming:** `serfel-<stage>-rehost-*`. In `dev` the literal prefix is `serfel-dev-rehost-`. Never hardcode account id `146476548567` in application code (CI already injects it).
- **Secrets:** DB creds come from the existing `serfel-dev-db-credentials` secret (import `dbSecretArn` from `infra/database`). Basic Auth creds come from a new `serfel-dev-rehost-basic-auth` secret. Never bake secrets into images or code.
- **Compute in VPC private subnets** (`privateSubnetIds` from `infra/vpc`), TLS to RDS, ARM64 for Lambdas (`architecture: "arm64"`).
- **PHP is EOL:** pin the `php:5.6-apache` base image by digest once resolved; it never changes.
- **Auth model:** node rehost routes use the Basic Auth authorizer (NOT Cognito). This is explicitly temporary (strangler swaps to Cognito later).

```typescript
import { timingSafeEqual } from "node:crypto";

function safeEqual(a: string, b: string): boolean {
  const ab = Buffer.from(a);
  const bb = Buffer.from(b);
  // timingSafeEqual throws on length mismatch; guard first (length is not secret).
  return ab.length === bb.length && timingSafeEqual(ab, bb);
}

export function verifyBasicAuth(
  authHeader: string | undefined,
  expected: { username: string; password: string }
): boolean {
  if (!authHeader) return false;
  const [scheme, encoded] = authHeader.split(" ");
  if (scheme !== "Basic" || !encoded) return false;
  const decoded = Buffer.from(encoded, "base64").toString("utf8");
  const sep = decoded.indexOf(":");
  if (sep < 0) return false;
  const username = decoded.slice(0, sep);
  const password = decoded.slice(sep + 1);
  return safeEqual(username, expected.username) && safeEqual(password, expected.password);
}
```

```typescript
const sm = new SecretsManagerClient({});
let cached: { username: string; password: string } | null = null;

async function getExpected() {
  if (cached) return cached;
  const secret = await sm.send(
    new GetSecretValueCommand({ SecretId: process.env.BASIC_AUTH_SECRET_ARN })
  );
  cached = JSON.parse(secret.SecretString!) as { username: string; password: string };

}

// HTTP API v2 simple-response authorizer.
export async function handler(event: {
  headers?: Record<string, string | undefined>;
```
